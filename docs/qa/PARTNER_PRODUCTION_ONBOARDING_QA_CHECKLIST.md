# Partner Production Onboarding QA Checklist

Use this checklist before inviting real production partners at scale.

## Public Registration

- [ ] `https://vendor.karigo.com.ng/register` loads on desktop.
- [ ] `https://vendor.karigo.com.ng/register` loads on mobile.
- [ ] Product Seller path is visible and usable.
- [ ] Service Provider path is visible and usable.
- [ ] Both path is visible and usable.
- [ ] No demo/test partner copy is shown to applicants.
- [ ] No secrets, OTPs, provider keys or internal URLs are visible.

## Product Seller Application

- [ ] Required business/contact fields are validated.
- [ ] Kano/Abuja launch-city handling is clear.
- [ ] Application confirmation is shown after submit.
- [ ] Admin Vendor Applications receives the application.
- [ ] Partner type is displayed to Admin.

## Service Provider Application

- [ ] Service categories include expanded SME Services categories.
- [ ] Service provider requirements are clear.
- [ ] Regulated categories remain review-gated.
- [ ] Admin can review the provider context.

## Mixed Partner Application

- [ ] Both product and service intent is captured.
- [ ] Admin can identify the partner as mixed.
- [ ] Product and service onboarding requirements are not confused.

## Activation And Workspace

- [ ] Approved partner receives activation/password setup path.
- [ ] Partner can set password.
- [ ] Partner can sign in to Partner Workspace.
- [ ] Partner can upload profile logo/cover image.
- [ ] Partner can upload onboarding documents.
- [ ] Product sellers can manage products.
- [ ] Service providers can manage services.

## Cleanup And Missing Profile

- [ ] Duplicate/test applications can move to Trash.
- [ ] Trashed applications are hidden from Active filter.
- [ ] Restore works for safe records.
- [ ] Permanent delete is blocked when protected history exists.
- [ ] Missing Partner profile screen shows clear onboarding/logout/support actions.

## Launch Guardrails

- [ ] No payout automation is activated.
- [ ] No provider app login outside Partner Workspace is activated.
- [ ] No live rides or ride dispatch is activated.
- [ ] No demo vendors/products/services appear on customer-facing surfaces.
- [ ] Admin audit/logging surfaces capture cleanup or review decisions where available.
