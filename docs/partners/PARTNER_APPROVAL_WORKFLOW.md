# Partner Approval Workflow

This workflow guides Admin review from application submission to launch readiness.

## Admin Review Path

1. Open Admin Portal.
2. Review Vendor Applications or Partner Applications.
3. Confirm partner type:
   - Product Seller
   - Service Provider
   - Both
4. Check city and service area.
5. Review submitted documents and notes.
6. Check duplicate/test records.
7. Approve, request changes, reject or move to Trash.

## Approval States

| State | Meaning | Admin Action |
| --- | --- | --- |
| Submitted | Application received. | Review identity, category and city. |
| Under Review | Admin is checking details. | Ask for missing information if needed. |
| Approved | Partner can proceed to activation/onboarding. | Ensure activation link and Partner Workspace access are available. |
| Needs Changes | Applicant must update details/documents. | Send safe applicant-visible note. |
| Rejected | Application is not accepted. | Keep internal reason clear and safe. |
| Trash | Duplicate/test/created-in-error application hidden from active lists. | Restore only if needed, delete only when safe. |

## Activation Bridge

After approval:

- Vendor/Partner record should exist or be linked.
- Partner user account should receive activation/password setup instructions.
- Partner should sign in at `https://vendor.karigo.com.ng`.
- Partner should complete profile, document and catalogue readiness.

## Launch Readiness Signoff

Approval does not automatically mean public launch. Before launch-ready status, Operations should confirm:

- active Partner profile;
- required documents reviewed;
- catalogue or service listings ready;
- city/service area supported;
- support/escalation contact confirmed;
- payment and reconciliation instructions understood.

## Cleanup Path

Use Trash for duplicate, test or created-in-error records. Permanent delete requires backend safety checks and typed confirmation.
