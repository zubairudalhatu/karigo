# Controlled account private handoff template

Store the completed handoff only in the owner-approved private credential system. Never commit the completed form, credentials, OTPs, recovery codes, personal tester data, or payment secrets to Git.

## Non-secret repository record

- City: [Kano or Abuja]
- Safe account label: [operations-safe label]
- Account purpose: [Customer, Ride Captain, Delivery Captain, Partner]
- Controlled group name: [group]
- Service: [service]
- Operating window: [start/end/timezone]
- Responsible owner role: [role, not personal contact data]
- Campaign exclusion confirmed: [yes/no]
- Admin audit reference: [non-secret reference]

## Private owner vault checklist

- Existing account ID and login identifier recorded privately.
- Password stored privately and never placed in Admin notes.
- Login prepared without a permanent OTP dependency.
- Recovery and device access assigned to authorised owners.
- No founder primary account used.
- No real card secret stored; approved test/payment method recorded privately.
- Customer profile uses safe, non-private information.
- Handoff date, receiving owner, expiry/review date, and revocation steps recorded.

The repository stores only this blank template.
