# End-to-End Transaction Drills

Create every drill in Admin before executing it. Link existing controlled account UUIDs and the resulting reference; never store passwords, OTPs, Ride PINs or payment secrets.

## Ride

Customer request -> Admin visibility -> eligible Captain -> manual assignment -> Captain accepts -> Customer sees Captain/vehicle -> arrival -> PIN shown at correct stage -> start -> destination -> completion -> receipt -> earnings -> audit timeline -> work lock released.

## Product and delivery

Customer order -> Partner receives -> accepts -> Delivery Captain assigned -> accepts -> pickup -> delivery -> Customer confirmation -> Partner earning -> Captain earning -> reconciliation record.

## SME Services

Customer request -> Admin review -> provider matching/assignment -> safe Customer update -> completion -> Customer review. Provider private contact remains hidden.

## Failure drills

Record payment failure, Customer/Captain cancellation, Partner rejection, support escalation and emergency pause. Confirm reversal/refund procedures where applicable and that no service resumes automatically.

Run relevant drills in both Kano and Abuja before `LIMITED_PUBLIC`. Mark `PASSED` only after evidence is reviewed.
